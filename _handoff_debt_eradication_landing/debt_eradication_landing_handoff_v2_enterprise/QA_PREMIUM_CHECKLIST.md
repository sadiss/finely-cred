# Premium QA Checklist

Before final delivery, verify:

## Visual quality

- [ ] Hero looks cinematic, not like a flyer.
- [ ] E-guide mockup is polished and not oversized.
- [ ] Gold CTA button has metallic shine and depth.
- [ ] Background has layered navy gradients, subtle texture, and gold atmosphere.
- [ ] Video block feels integrated and premium.
- [ ] Discovery cards have clean spacing, icons, border highlights, and hover states.
- [ ] Bottom CTA feels like a high-end conversion panel.

## Brand constraints

- [ ] No logo in header.
- [ ] No logo in footer.
- [ ] No recreated logo anywhere.
- [ ] Fallback e-guide mockup has no logo.
- [ ] Final production guide PNG must be approved and logo-free.

## Functionality

- [ ] Route loads at `/debt-eradication-guide`.
- [ ] Lead form validates email.
- [ ] Lead form submits through `submitLeadCapture`.
- [ ] Mobile layout does not overflow.
- [ ] Desktop hero does not crowd the copy.
- [ ] No TypeScript or console errors.

## Launch copy

- [ ] Replace placeholder stats/testimonials with approved proof before launch.
- [ ] Review debt/credit claims for compliance before publishing.
