# Layout card rule — Marketing Desk

## Rule

Marketing Desk sections sit on the page background with real side padding (`px-4 sm:px-6 lg:px-8`) inside `max-w-7xl`. Lists use `gap-4` or `gap-6` grids. A result can be one card. A card does not wrap another card. Long setup and schedule blocks stay collapsed.

## SHIPPED

Find (`helper=find`) is a hero ask, a KPI row, and a review grid. The old sticky panel that held a location field, run details, setup steps, and exception cards inside more cards is gone.

The desk page wrapper is `max-w-7xl` with side padding so the column is not flush against the admin rail.

## PARTIAL

Board, Mail, Clean, Ruth, and Desk home still use a single header band or catalog card for their own tools. Those are one surface, not cards nested inside the Find panel. Lead Intel “More filters” is collapsed; the wizard shell around the source steps is still one panel.
