# Consumer-favoring restore sequencing (Finely)

## Rights-first framing

Partners can **dispute inaccurate reporting**, **request debt validation**, **document every step**, and **escalate factually** after disciplined rounds. Finely does not teach helplessness or illegal shortcuts.

## Sanz order (when risk exists)

1. Debt / collection / summons triage first.
2. Validation on collector debt before bureau blitz.
3. Bureau restore rounds with screenshot exhibits (FCRA factual disputes).
4. Complaints (CFPB) after failed rounds when warranted.
5. BUILD / funding-readiness as separate honesty conversation.

## Product path

Portal → Credit Restore → report upload → dispute candidates → letter builder → evidence gate → mail → tasks for Round 2.

## Metro 2 / e-OSCAR (plain)

Furnishers report structured data; bureaus publish consumer-readable tradelines. Disputes often route to furnishers via industry networks. **Field mismatches** on the report are factual dispute angles—not magic deletion codes.
