# FICO score models — specialist talk-track (research lock)

Educational only. Never quote a single number without **model + bureau + purpose + inquiry type (soft/hard)**.

## FICO versions (consumer / general)

| Model | Notes |
| --- | --- |
| **FICO 8** | Widely used for cards and many lenders; familiar baseline for education. |
| **FICO 9** | Paid collections can weigh differently vs FICO 8; medical collections treated differently in some cases — adoption varies by lender. |
| **FICO 10 / 10T** | Newer generation; **10T** uses trended data (balances over time). Adoption is **not** universal — always ask which model a creditor pulled. |

**Never teach “FICO 5.8”** as a real model — it is a common mashup of “FICO 5” + “FICO 8” confusion.

## Classic mortgage tri-merge (often called “mortgage scores”)

Lenders commonly use **older** FICO generations per bureau:

- **Equifax:** Beacon **5.0** (FICO 5 family)
- **Experian:** **FICO 2** (historically “Experian/Fair Isaac Risk Model v2”)
- **TransUnion:** **FICO 4** (classic 04)

**Middle score** rule: for many mortgage decisions the **median** of the three bureau scores is used (when three are present). Educational shorthand — underwriting varies.

**“FICO 5.4”** is **unverified jargon** in the wild — do **not** assert it as an official product name. Teach **Beacon 5.0** on Equifax instead.

## VantageScore (free apps vs GSE)

| Version | Where you see it |
| --- | --- |
| **VantageScore 3.0** | Common on free credit apps and some portals — **not** the same number as FICO. |
| **VantageScore 4.0** | Used in some mortgage/GSE-adjacent paths; adoption expanding — still not identical to FICO 8/9/10. |

Say clearly: “Your app score is a **model** — ask what the lender will pull for **this** product.”

## Industry scores

- **FICO Auto** and **FICO Bankcard** — industry-specific variants; numbers differ from generic FICO.
- **UltraFICO** — opt-in program linking deposit behavior; optional, not universal.
