# Track I — Credit score intelligence

**Goal:** Teach specialists to explain **why numbers differ** without selling a score or promising approvals.

## Consumer-first rules

1. Never quote a number without **model + bureau + purpose + soft/hard**.
2. Free apps often show **VantageScore 3.0** — not the same as a mortgage tri-merge.
3. **No guarantees** — restore documents facts; lenders decide.
