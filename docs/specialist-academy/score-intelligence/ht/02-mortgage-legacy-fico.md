# FICO ipotèk klasik (tri-merge)

Anpil ipotèk toujou itilize **vye jenerasyon FICO** pa biwo — pa menm ak Vantage nan app gratis.

## Tablo (edikasyon)

| Biwo | Modèl ipotèk komen |
| --- | --- |
| Equifax | **Beacon 5.0** (fanmi FICO 5) |
| Experian | **FICO 2** |
| TransUnion | **FICO 4** |

## Nòt mitan (middle)

Lè gen twa nòt, anpil program itilize **medyan** — règ varye. Pa pwomèt to ak yon sèl nòt.

## “FICO 5.4”

Jagon sou entènèt — **pa** non ofisyèl Finely. Anseye **Beacon 5.0** sou Equifax.

## “FICO 5.8”

Pa yon modèl reyèl — konfizyon 5 + 8.

*Edikasyon sèlman.*
