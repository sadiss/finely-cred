# F02 — Validation first

**Front:** Why send validation to the collector before relying only on bureau dispute letters for the same debt?

**Back:** Validation (FDCPA §809 educational framing) demands verification from the collector and can pause improper collection while the file is built. It reduces the client being pressured without documentation — and keeps Finely’s story consistent before FCRA bureau rounds.
