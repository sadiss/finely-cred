# F-BUILD-05 — Installment

**Front:** Why teach “one installment” in BUILD?

**Back:** Healthy **installment** reporting (auto, personal, student-style, etc.) supports **credit mix** education and shows paid-as-agreed history. One teaching target — not a requirement for every lender. Accurate reporting only; no invented tradelines.

---

## Teach this like a lesson

### Plain explanation
Use the flash answer as the headline, then coach the **why**, **timeline**, and **portal clicks** — never promise deletions, scores, or court wins.

### Step-by-step
1. Read the partner file and current tradelines.
2. Match the card topic to the correct SOP (see WORKFLOW-MAP).
3. Draft or select the template; OCR if uploading prior letters.
4. Log sends in the portal; screenshot evidence the same day.
5. Debrief in Kreyòl when needed; store English letter text.

### Haitian desk
Explain concepts sit-together; keep bureau letters in English unless translating concepts only.

### Compliance
Educational process only — not legal advice. Debt may remain after restore.
