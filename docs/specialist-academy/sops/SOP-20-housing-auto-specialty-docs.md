# SOP-20 — Housing & auto specialty documentation

**Purpose:** Vault discipline for **RESPA/foreclosure** and **UCC/repo** files without practicing law.

## Mortgage / foreclosure

- [ ] Servicer statements, modification letters, breach notices uploaded
- [ ] Tradeline + public record screenshots
- [ ] FCRA dispute only for exhibit-backed inaccuracies
- [ ] Counsel referral if foreclosure complaint served

## Auto / repossession

- [ ] Repo notice, sale, deficiency letters
- [ ] Playbook tasks: disposition + accounting (`negativePlaybooks` repossession)
- [ ] Validation if collector assigned debt
- [ ] Summons for deficiency → SOP-10

## Example

Foreclosure status on report but partner has HAMP approval letter—exhibit + investigation letter; parallel servicer call by partner.
