# SOP-15 — Funding-readiness checklist (pre–Nora soft handoff)

**Purpose:** Confirm restore/debt work is documented and BUILD education is honest **before** introducing Nora or funding language.

**Not a loan approval step.** Finely does not underwrite. Nora (when configured) decides separately.

---

## Gate: do not run this checklist while…

- Active summons clock unmanaged (SOP-10).
- Fresh collector contact with no validation plan (SOP-08/09).
- Client expects “approved funding” as part of restore package.

---

## A — Restore & debt file hygiene

- [ ] SOP-14 intake complete; round stage documented
- [ ] Debt triage classification on file (`debt_first` / `parallel` / `bureau_only`)
- [ ] Validation/summons track documented if applicable
- [ ] Vault: report, exhibits, letters, mailing proof
- [ ] Open disputes aligned with evidence (SOP-13)
- [ ] No promise of deletion, score, or funding outcome in partner messages

---

## B — BUILD profile review (educational underwriting lens)

Coach against **typical teaching targets** — not lender law:

| Check | Question for specialist |
| --- | --- |
| Revolving (≥2) | At least two revolving trades in good standing, or clear plan with timelines? |
| Mix | Client understands mix (not all one product type)? |
| Installment (≥1) | At least one healthy installment reporting, or realistic path? |
| AU honesty | If AU discussed: client told impact is limited/conditional; no score guarantee? |
| Utilization | Balances vs limits reviewed; pay-down plan if high? |
| Inquiries | Recent hard pulls explained; application pacing discussed? |
| Payment history | On-time payment discipline on open accounts emphasized? |

- [ ] BUILD notes added to file (separate from dispute narrative)
- [ ] Any “premium / black card” talk labeled **aspirational education** in notes

---

## C — FICO-style literacy (client was told)

- [ ] Client heard five-factor **industry education** (~35/30/15/10/10 shorthand) — not “Finely’s formula”
- [ ] Client heard lenders use **more than score** (income, DTI, reserves, policy)

---

## D — Nora soft handoff (only if program + entitlements allow)

- [ ] Script used: Finely ≠ lender; Nora separate pathway
- [ ] No approval, rate, card, or timeline promises
- [ ] Wealth Paths / entitlements verified in portal vs verbal claims
- [ ] Referral logged per tenant process

---

## Outcomes

| Result | Next step |
| --- | --- |
| **Ready for conversation** | Warm intro to Nora/Wealth Paths per product config — still no approval promise |
| **BUILD gaps only** | Continue parallel BUILD coaching during restore rounds |
| **Restore/debt blocked** | Return to SOP-08–11; defer funding talk |
