# SOP-17 — FCRA investigation package

**Purpose:** Standardize Round 1–2 bundles for bureau investigations.

## Package contents

- [ ] Cover sheet with round number and date
- [ ] Account list matching exhibits
- [ ] Per-account screenshot (SOP-13)
- [ ] PDF letter + certified mail proof
- [ ] Bureau response PDF (Round 2+)
- [ ] Task board updated

## Example

Two EX tradelines disputed; Exhibits A–B; Round 2 quotes “verified as reported” and requests MOFV source records.

## Aligns with

SOP-11, Track H FCRA lesson.
