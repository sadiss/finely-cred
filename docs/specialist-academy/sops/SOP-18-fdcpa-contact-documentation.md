# SOP-18 — FDCPA contact documentation

**Purpose:** Create defensible records of collector contact without coaching harassment.

## Steps

1. Log each call: date, time, collector name/number, summary (facts only).
2. Save letters and voicemails to Vault.
3. Cross-check validation timeline (SOP-09).
4. If mini-Miranda not given, note factually—do not threaten counter-lawsuits as Finely.

## Example

Collector calls 6×/day after validation mailed—log pattern; follow-up letter; consider lead review for AG/CFPB **after** SOP-12 timing if reporting-related harm documented.

## Escalate counsel

Threats of immediate arrest, false representation of government affiliation.
