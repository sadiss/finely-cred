# SOP-16 — Metro 2 / furnisher factual disputes

**Purpose:** Document **field-level** inaccuracies on tradelines without “magic code” language.

## Steps

1. Screenshot tradeline with visible status, dates, balance, payment grid.
2. List disputed fields in a table (report value vs partner document if any).
3. Draft Round 1 using `negativePlaybooks` MOFV clauses—not generic Metro 2 spam.
4. Vary letter structure (SOP-13).

## Example

Repo sale letter date ≠ reported disposition date → exhibit both; investigation request.

## Escalate counsel

Summons, replevin, or criminal threats.
