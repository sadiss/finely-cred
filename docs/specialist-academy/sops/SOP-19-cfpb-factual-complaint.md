# SOP-19 — CFPB factual complaint (extends SOP-12)

**Purpose:** File **one** coherent CFPB narrative after disciplined rounds.

## Preconditions

Same as SOP-12, plus Track H CFPB lesson completed by specialist.

## Steps

1. Draft facts-only timeline (validation → rounds → responses).
2. Attach Vault PDFs (letters, tracking, bureau mail, exhibits).
3. State requested correction (investigate/correct/delete if inaccurate).
4. Submit; save complaint ID; notify partner (no outcome promise).
5. No duplicate filings within 14 days unless new material fact.

## Example

Post–Round 2 MOFV refusal on repo balance mismatch—complaint cites account label and dates.
