# FCRA — presizyon, envestigasyon, dispute

**FCRA** regle kijan biwo ak furnisher jere **presizyon** ak **dispute**. Travay restore Finely la chita isit la—toujou edikasyon, pa pwomèt efase dèt ki vrè.

## Ide kle

| Tèm | Sans |
| --- | --- |
| Presizyon | Dat, balans, estati, pwopriyete kont |
| Dispute | Mande envestigasyon ak prèv |
| Permissible purpose | Enquiry dwe gen rezon legal (kredi, asirans, elatriye) |
