# CFPB — factual complaints after disciplined restore

The **Consumer Financial Protection Bureau** complaint portal is a **structured escalation** tool—not a first-day weapon. Finely uses it **after** restore rounds fail when facts support a coherent story (**SOP-12**, **SOP-19**).

## Why it matters

Emotional spam complaints hurt partner credibility and waste regulator attention. A **clean Vault** + **timeline** makes CFPB appropriate when furnishers or bureaus stall.

## When CFPB fits (educational)

- Round 1 **and** Round 2 completed (or documented exception).
- Specific inaccuracy or non-response documented.
- Exhibits: letters, tracking, bureau replies, screenshots.
- Lead approval per tenant policy.

**Not** when: validation window just opened; summons clock running without counsel plan; facts contradict prior letters.

## Step-by-step factual complaint

1. Outline one narrative: dates, accounts, harm (inaccurate reporting), requested remedy (investigate/correct).
2. Attach PDFs already in Vault—do not invent.
3. File **one** complaint per logical chain; log confirmation ID in tasks.
4. Continue Round 3 only if playbook supports—no contradictory asks.

## Example — post–Round 2 auto repo tradeline

Bureau twice “verified” repo balance inconsistent with disposition letter partner uploaded. CFPB narrative quotes Round 2 dates, attaches exhibit, requests correction. No insults, no duplicate filings next day.

## Example — collector + bureau (careful sequencing)

Validation sent; collector still reporting without response. Debt track documented; bureau dispute on reporting accuracy separate. CFPB mentions **both** only if timeline is consistent.

> **Mistake:** CFPB before any certified mail.
