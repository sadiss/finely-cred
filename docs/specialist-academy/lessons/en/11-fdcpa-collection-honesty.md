# FDCPA collection honesty & validation

## Learning objectives

- Explain **validation** under FDCPA § 809 (educational) without promising lawsuit outcomes.
- Sequence **debt-first** work ahead of blind bureau rounds when collector risk is live.
- Document **cease communication** requests and attorney involvement appropriately.

## Validation framework

1. **Initial communication** — consumer receives required disclosures (mini-Miranda concept).
2. **Validation request** — consumer disputes debt validity within statutory window (state counsel when unclear).
3. **Collector pause** — must cease collection until verification provided (with exceptions — teach nuance).
4. **Vault** — store PDFs of letters, certified receipts, and collector responses.

## What validation is not

- Not a magic delete button for accurate tradelines still reported by original creditor.
- Not a substitute for bankruptcy, settlement, or defense in active litigation.
- Not Finely “legal advice” — escalate to counsel for summons/answer deadlines.

## Pairing with restore

| Signal | Priority |
|--------|----------|
| Active collector calls + unknown balance | Validation + debt triage |
| Summons served | Litigation Command — freeze bureau spam |
| Charged-off tradeline only on bureau | FCRA dispute track with evidence |
| Repo deficiency letter | Repo literacy + validation where applicable |

## Script honesty (partner-facing)

> “We help you **request verification** and organize responses. We do not tell collectors what they must do — we document what they **did** provide.”

## Specialist checklist

- [ ] Collector identity and account number logged (redact in tickets)
- [ ] Validation letter template version tracked in Templates
- [ ] Bureau rounds paused if SOP-10 litigation flag is on
- [ ] Partner consent for SMS/email outreach documented
