# Debt-first & validation

When a partner has **live collection activity** or an account that can still generate **summons risk**, Finely treats the **collector track** as a gate—not an afterthought. Validation is the first disciplined move on collector debt so the file shows you requested verification **before** pressure escalates.

## Why it matters

Collectors can report, call, and initiate legal workflows. Bureau disputes alone do not replace a **timely validation request** under the consumer protection framework specialists study as **FDCPA §809** (15 U.S.C. § 1692g)—explained here as **education**, not case-specific legal advice.

Validation creates a clear timeline: first communication → written validation request → documented response or non-response → next fork (debt dispute, bureau accuracy dispute, or measured escalation).

## Step-by-step (SOP-09)

1. Confirm **first written communication date** from collector letter or portal intake.
2. Select template: `debt_validation_request` / `debt_validation_1692g` in product.
3. Customize collector name, address, and account reference from the letter or report—vary opening structure (SOP-13).
4. Mail **certified** when possible; scan receipt to Vault.
5. Log tasks: follow-up if no response; do not promise deletion.
6. Update Debt & Summons Center scenario (`validation_period` / `first_contact`).
7. Only then schedule bureau disputes that **align** with validation facts.

## Example — validation window (desk-friendly)

**Facts:** On March 3, partner receives first letter from **Summit Receivables** for $1,842 tied to a synced card. TransUnion shows the collection tradeline with status “open.”

**Specialist actions:**

1. Triage: `debt_first`.
2. Validation letter cites account as reported; requests itemization and verification method.
3. Certified mail March 5; tracking uploaded.
4. Partner message (warm Finely voice): “We started the collector verification path first so your file is orderly. Bureau work on reporting accuracy is sequenced next.”
5. Screenshot **TU tradeline** for later Round 1 exhibit.

> **Example — Haitian desk:** Explain in Kreyòl that the **English** letter is normal for U.S. collectors. Review the mailing date together—“tout bagay gen dat.”

## Example — do not validate twice blindly

**Facts:** Partner already mailed validation 20 days ago with proof; no response.

**Actions:** Use `debt_validation_followup_no_response` with **new paragraph order**, not a duplicate PDF. Document prior send date in notes. Do not tell partner the collector “must delete” the tradeline.

> **Mistake:** Sending three identical validations in one week reads as spam and weakens credibility.

## Common mistakes

- Skipping validation because “we only do credit repair.”
- Quoting §809 as a guaranteed win lawsuit.
- Starting Round 1 deletion language on the same collector account before validation is logged.
