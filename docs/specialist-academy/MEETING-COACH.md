# Meeting coach — Sanz-style trainee video sessions

Use this checklist when Sanz (or a lead coach) runs a **live video** review. Goal: verify the trainee can **sequence** work, not recite slogans.

**Duration:** 45–60 minutes typical  
**Prep (trainee):** One real or scrubbed practice file open — Debt Center, Collections, Disputes, Documents Vault, Tasks.

---

## Before the call (trainee)

- [ ] Printed or pinned [WORKFLOW-MAP.md](./WORKFLOW-MAP.md)
- [ ] Cards F01–F14 reviewed in last 72 hours
- [ ] SOP-14 intake notes filled for the practice file
- [ ] Camera on; screen share ready

---

## Opening (5 min) — coach

- [ ] Confirm compliance framing spoken once: educational process, no guarantees, Nora separate
- [ ] Ask: “What round is this file in, and how do you know?”
- [ ] Ask: “Any debt, collection, or summons risk — yes or no, and evidence?”

**Pass:** Trainee cites Vault docs or explicit “none noted” with intake date.

---

## Debt gate quiz (10 min)

| Question | Pass signal |
| --- | --- |
| Fresh collector letter on report — first move? | Validation path (SOP-09), not immediate mass bureau deletion |
| Same client, no collector contact, only old charge-off | Bureau track with evidence; debt-first optional with rationale |
| Client mentions “court date” | SOP-10: upload, calendar, counsel talk — pause blind Round 1 |

- [ ] Trainee draws fork on workflow map without reading verbatim

---

## Validation drill (8 min)

- [ ] Trainee names **FDCPA §809** as educational framing (not “they must delete”)
- [ ] Identifies proof of mailing plan (certified + save PDF)
- [ ] Explains why validation reduces “rush to sue without proof” **risk** (educational)

**Red flag:** Guaranteed deletion or “collector can’t report ever.”

---

## Evidence & OCR (8 min)

- [ ] Open one collection or tradeline — show screenshot evidence on **that** account
- [ ] Explain one intentional variation vs prior letter (SOP-13)
- [ ] No cookie-cutter: trainee describes how they’d vary Round 2 opening

---

## Restore rounds (10 min)

- [ ] Round 1 vs 2 vs 3 — different purpose in one sentence each
- [ ] Points to Credit Intel / task timeline: evidence → dispute → mail → follow-up
- [ ] Names one factual dispute from report (date, balance, status) — not fraud fantasy

---

## Complaints & escalation (5 min)

- [ ] When CFPB/AG is appropriate (post failed rounds, clean narrative)
- [ ] When it is **not** (Round 1 just mailed, emotional only)

---

## Nora / funding handoff (3 min)

- [ ] Finely ≠ lender script
- [ ] No approval promise
- [ ] Funding-readiness = documented file, not score guess

---

| Area | 1 — redo | 2 — coach with file | 3 — solo-ready |
| --- | --- | --- | --- |

**Rule:** Any **1** in Sequencing or Summons → no solo ownership yet.
