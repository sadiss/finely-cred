# Finely brand kit lock — sales packs / one-sheets / guide v2

**Applies to:** all `docs/sales-packs/finely/**` HTML, email drafts, SMS, one-sheets, and guide v2 covers.

## Colors (only)

| Token | Hex | Use |
| --- | --- | --- |
| Primary | `#fbbf24` | Accents, links, key labels |
| Shell | `#0b1110`, `#060908` | Page backgrounds, cards |
| Text | `#f8faf9` | Body on dark |
| Ink on gold | `#1a1400` | Text on CTA / gold buttons |
| CTA metal gradient | `#ffeaa7` → `#fdcb6e` → `#f39c12` → `#d68910` | Primary buttons only |

**Never** use `#39ff14` as marketing primary on Finely cold creatives. **Never** use legacy “shield-F” marks.

## Typography

- **Font:** Inter (Google Fonts or system fallback).
- **FINELY** — ALL CAPS, `letter-spacing: 0.14em`, `font-weight: 200`.
- **Cred** — title case, same family, weight 200.

## Logo (official only)

| File | Path |
| --- | --- |
| SVG wordmark + medallion | `public/brand/finely-cred-logo.svg` |
| Dark-bg PNG | `public/brand/finely-cred-logo-dark.png` |
| Mark / medallion | `public/brand/finely-cred-mark.png` |

HTML one-sheets: **embed** SVG or PNG (see `html-one-sheets/`). Print/PDF without embed: stacked **FINELY** / **Cred** wordmark per `_brand/wordmark-stack.html`.

**No Nora logo** on Finely-primary cold creatives. Nora handoff = text link only.

## Voice

- Say: **restore**, **file accuracy**, **wealth tool**, **debt honesty**, **educational documentation**.
- Avoid: **“credit repair”** as lead hook, score guarantees, deletion promises.
